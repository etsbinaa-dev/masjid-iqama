# أوقات الإقامة — تطبيق أندرويد

تطبيق يعرض أوقات الإقامة في مسجد الحي، ويرسل تنبيهاً قبل كل إقامة بعدد الدقائق الذي يختاره المستخدم.

## تحميل التطبيق
آخر نسخة دائماً هنا:
https://github.com/etsbinaa-dev/masjid-iqama/releases/latest/download/masjid-iqama.apk

## تغيير الأوقات لكل أهل الحي
1. افتح الملف `times.json` في هذا المستودع.
2. اضغط أيقونة القلم (Edit).
3. غيّر الوقت المطلوب بنفس الشكل `"17:15"` (نظام 24 ساعة).
4. اضغط **Commit changes**.

يقرأ التطبيق الأوقات الجديدة عند فتحه، ويضبط التنبيهات عليها تلقائياً. لا حاجة لإرسال نسخة جديدة من التطبيق.

## الملفات
- `www/index.html` — شاشة التطبيق ومنطق التنبيهات.
- `times.json` — أوقات الإقامة.
- `android/` — مشروع أندرويد (Capacitor).
- `.github/workflows/build-apk.yml` — يبني ملف APK تلقائياً عند كل تعديل في الكود.
